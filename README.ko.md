# SpotI

[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

케이스에서 반쯤 꺼낸 LP 모양을 한, 항상 위에 떠 있는 아주 작은 데스크톱
동반자입니다. 데스크톱 어디든 드래그해서 놓을 수 있고, 마우스를 올리면
현재 재생 중인 곡을 보고 재생을 제어할 수 있습니다.

## 기능

- 드래그 가능한 데스크톱 펫 — 자기 자신의 그림 부분을 제외하면 클릭이
  그대로 통과됩니다
- 호버 팝업: 앨범 아트, 곡/아티스트 정보, 재생/일시정지/다음곡/이전곡,
  탐색 가능한 진행 바, 볼륨
- PKCE 방식 Spotify 로그인(직접 발급받은 Client ID 사용, 공유 시크릿 없음) —
  앱 안에서 바로 설정
- 키보드 미디어 키 전역 지원(재생/일시정지/다음곡/이전곡)
- 설정 창
  - **일반** — 언어, 볼륨, 불투명도, 시작 시 자동 실행, SpotI 크기,
    트랙 변경 알림(소리 포함), 연동 속도, 팝업 반응 속도, 디스크 회전
    애니메이션, 미디어 키, 시작 시 숨기기, 설정 초기화
  - **테마** — 라이트/다크 모드, 폰트 컬러, LP 컬러, 케이스 컬러,
    테두리 표시 여부 + 테두리 색
  - **기록** — 1년치 청취 기록 히트맵, 연속 기록, 날짜별 베스트 음반
  - **Spotify** — Client ID 설정, 연결 상태, 버전 정보
- 한국어, 영어, 중국어, 일본어 UI 지원

## 설치 및 실행

1. `npm install`
2. `npm start` (또는 `npm run dev`)로 SpotI를 실행합니다
3. https://developer.spotify.com/dashboard 에서 자신의 Spotify 앱을
   만들고, **Create app** 클릭 후 **Redirect URI**를 정확히 아래로
   설정합니다:
   ```
   http://127.0.0.1:8765/callback
   ```
4. SpotI에서 펫을 우클릭 → **설정** → **Spotify** 탭에서 앱의
   **Client ID**를 붙여넣고 **저장**을 누릅니다.
5. 펫에 마우스를 올리고 **Spotify 연결**을 클릭합니다.

끝입니다 — 파일을 직접 수정할 필요가 없습니다. (개발/고급 사용자는 대신
`SPOTIFY_CLIENT_ID` 환경 변수를 설정할 수 있으며, 이 값이 우선 적용됩니다.)

## 배포용 빌드 만들기

`npm run dist`를 실행하면 `release/` 폴더에 두 가지가 만들어집니다:

- **`SpotI-<version>-nsis.exe`** — 일반적인 Windows 설치 프로그램
  (시작 메뉴 바로가기, 제거 프로그램 포함)
- **`SpotI-<version>-portable.exe`** — 설치 과정도, 관리자 권한도 필요
  없이 더블클릭만 하면 바로 실행되는 단일 실행 파일

> **Windows에서 `npm run dist` 중 "Cannot create symbolic link" 오류가
> 나나요?** electron-builder가 자체 도구를 압축 해제하는 과정에서
> 심볼릭 링크를 만들 권한이 필요합니다. **설정 → 개인정보 및 보안 →
> 개발자용 → 개발자 모드**를 켜신 뒤 `npm run dist`를 다시 실행하세요
> — 한 번만 켜두면 계속 유지됩니다.

빌드된 앱을 실행하는 사람은 각자 설정 화면(위 4번 단계)에서 자신의
Client ID를 입력하면 됩니다 — 빌드 안에 Spotify 관련 정보가 미리 담겨
있지 않습니다.

## 참고

- 재생 제어(재생/일시정지/다음곡/이전곡, 탐색, 볼륨)는 **Spotify
  Premium**과 이미 활성화된 Spotify Connect 기기(데스크톱 앱, 폰,
  웹 플레이어 등 어딘가에서 재생 중인 상태)가 필요합니다.

## 기술 스택

Electron + TypeScript, `electron-vite`로 빌드. 별도 UI 프레임워크 없이
바닐라 DOM 사용. 테스트는 `vitest`(`npm test`)로 진행합니다.
