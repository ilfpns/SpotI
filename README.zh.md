# SpotI

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

一个始终置顶的超小型桌面伙伴 —— 造型是从封套里半滑出来的黑胶唱片 ——
安静地待在你的桌面上，控制 Spotify 播放。可以把它拖到桌面任意位置；
把鼠标悬停在它上面就能看到正在播放的内容并进行控制。

## 功能

- 可拖动的桌面宠物，除了它自身的图案区域外，其余部分点击可穿透
- 悬停弹窗：专辑封面、曲目/艺术家信息、播放/暂停/下一曲/上一曲、
  可拖动的进度条、音量
- 通过 PKCE 方式登录 Spotify（使用你自己申请的 Client ID，没有共享密钥），
  直接在应用内完成配置
- 支持键盘媒体键全局控制（播放/暂停/下一曲/上一曲）
- 设置窗口
  - **通用** —— 语言、音量、不透明度、开机自动启动、SpotI 大小、
    曲目切换通知（含提示音）、同步速度、弹窗消失延迟、唱片旋转动画、
    媒体键、启动时隐藏、重置设置
  - **主题** —— 浅色/深色模式、字体颜色、唱片颜色、外壳颜色、
    边框显示开关 + 边框颜色
  - **记录** —— 一整年的收听记录热力图、连续天数、每日播放最多的曲目
  - **Spotify** —— Client ID 设置、连接状态、版本信息
- 支持韩语、英语、中文、日语界面

## 安装与运行

1. `npm install`
2. 运行 `npm start`（或 `npm run dev`）启动 SpotI
3. 前往 https://developer.spotify.com/dashboard 创建你自己的 Spotify
   应用，点击 **Create app**，并将 **Redirect URI** 精确设置为：
   ```
   http://127.0.0.1:8765/callback
   ```
4. 在 SpotI 中右键点击宠物 → **设置** → **Spotify** 标签页，粘贴你的
   应用 **Client ID**，然后点击 **保存**。
5. 将鼠标悬停在宠物上，点击 **连接 Spotify**。

就这样 —— 不需要手动编辑任何配置文件。（进阶/开发者用户也可以设置
`SPOTIFY_CLIENT_ID` 环境变量，该值会优先生效。）

## 构建可分发的应用

运行 `npm run dist` 会在 `release/` 目录下生成两种产物：

- **`SpotI-<version>-nsis.exe`** —— 常规 Windows 安装程序（含开始菜单
  快捷方式和卸载程序）。
- **`SpotI-<version>-portable.exe`** —— 单个独立可执行文件，无需安装
  步骤、无需管理员权限，双击即可运行。

运行该应用的每个人都会在设置界面（上面第 4 步）中配置自己的 Client ID ——
构建产物本身不包含任何 Spotify 相关的固定信息。

## 说明

- 播放控制（播放/暂停/下一曲/上一曲、拖动进度、音量）需要
  **Spotify Premium** 账户，并且需要有一个已激活的 Spotify Connect
  设备（桌面客户端、手机或网页播放器等，任意一处正在播放即可）。

## 技术栈

Electron + TypeScript，使用 `electron-vite` 构建。未使用 UI 框架 ——
原生 DOM。使用 `vitest` 进行测试（`npm test`）。
