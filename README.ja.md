# SpotI

[English](README.md) · [한국어](README.ko.md) · [中文](README.zh.md)

ケースから半分スライドして出てきた LP レコードの姿をした、常に最前面に
表示される小さなデスクトップの相棒です。デスクトップのどこにでもドラッグ
でき、カーソルを合わせると今再生中の曲を確認したり、再生を操作したり
できます。

## 主な機能

- ドラッグ移動可能なデスクトップペット。自分自身のイラスト部分以外は
  クリックがそのまま下のウィンドウへ通過します
- ホバー時のポップアップ：アルバムアート、曲名/アーティスト、
  再生/一時停止/次の曲/前の曲、シーク可能な進行バー、音量
- PKCE 方式による Spotify ログイン（自分専用の Client ID を使用、
  共有シークレットなし）— アプリ内でそのまま設定可能
- キーボードのメディアキーによるグローバル操作（再生/一時停止/次の曲/
  前の曲）に対応
- 設定ウィンドウ
  - **一般** — 言語、音量、不透明度、スタートアップ時に起動、SpotI の
    サイズ、トラック変更通知（通知音あり）、同期速度、ポップアップの
    消失遅延、ディスク回転アニメーション、メディアキー、起動時に非表示、
    設定のリセット
  - **テーマ** — ライト/ダークモード、フォントカラー、LP カラー、
    ケースカラー、枠線の表示切り替え + 枠線カラー
  - **履歴** — 1 年分の再生履歴ヒートマップ、連続記録、日別のベスト
    トラック
  - **Spotify** — Client ID の設定、接続状態、バージョン情報
- 韓国語・英語・中国語・日本語の UI に対応

## セットアップ

1. `npm install`
2. `npm start`（または `npm run dev`）で SpotI を起動します
3. https://developer.spotify.com/dashboard で自分の Spotify アプリを
   作成し、**Create app** をクリックした後、**Redirect URI** を
   正確に次の値に設定します:
   ```
   http://127.0.0.1:8765/callback
   ```
4. SpotI 上でペットを右クリック →**設定** → **Spotify** タブで、
   作成したアプリの **Client ID** を貼り付けて **保存** をクリックします。
5. ペットにカーソルを合わせて **Spotify に接続** をクリックします。

これだけです — 設定ファイルを手動で編集する必要はありません。
（上級者・開発者はこれに代えて `SPOTIFY_CLIENT_ID` 環境変数を設定する
こともでき、その場合はそちらが優先されます。）

## 配布用ビルドの作成

`npm run dist` を実行すると、`release/` フォルダに次の 2 つが生成されます:

- **`SpotI-<version>-nsis.exe`** — 通常の Windows インストーラー
  （スタートメニューのショートカット、アンインストーラー付き）。
- **`SpotI-<version>-portable.exe`** — インストール不要・管理者権限
  不要で、ダブルクリックするだけで起動できる単一の実行ファイル。

> **Windows で `npm run dist` 中に「Cannot create symbolic link」と
> 出る場合**: electron-builder が自身のツールを展開する際にシンボリック
> リンクを作成する権限が必要です。**設定 → プライバシーとセキュリティ →
> 開発者向け → 開発者モード** をオンにしてから `npm run dist` を
> やり直してください — 一度オンにすれば以降は不要です。

ビルドされたアプリを実行する人は、それぞれ設定画面（上記手順 4）で
自分の Client ID を設定します — ビルド自体には Spotify 関連の情報は
一切埋め込まれていません。

## 補足

- 再生操作（再生/一時停止/次の曲/前の曲、シーク、音量）には
  **Spotify Premium** と、すでにアクティブな Spotify Connect デバイス
  （デスクトップアプリ、スマートフォン、Web プレーヤーなど、どこかで
  再生中であること）が必要です。

## 技術スタック

Electron + TypeScript、`electron-vite` でビルド。UI フレームワークは
使用せず素の DOM を使用。テストは `vitest`（`npm test`）で実行します。
